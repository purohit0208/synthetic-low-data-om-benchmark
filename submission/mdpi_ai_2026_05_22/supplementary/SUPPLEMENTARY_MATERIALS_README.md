# Supplementary Materials README

This supplementary package supports the manuscript titled "A Synthetic Low-Data Benchmark for Trustworthy AI-Based Industrial Operation and Maintenance Decision Support".

Repository: https://github.com/purohit0208/synthetic-low-data-om-benchmark

Contents expected in the public repository:

- synthetic data generator and leakage audit;
- configuration and metadata files;
- generated synthetic dataset in CSV/Parquet;
- train/validation/test, label-scarcity, random, and site-held-out split files;
- model-training, calibration, routing, evaluation, and explanation scripts;
- result tables and publication figures.

Data boundary: all records are synthetic. No real industrial data, personal data, confidential project data, proprietary institutional material, or third-party operational records are included.
